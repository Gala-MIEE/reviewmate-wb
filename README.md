# ReviewMate для Paperform — отзывы с Wildberries, Ozon и Яндекс Маркета

Сервис забирает отзывы и вопросы покупателей, разбирает их (тема, тональность, приоритет, есть ли вопрос или пожелание) и готовит черновик ответа. Менеджер правит черновик и публикует его. Подходящие отзывы сервис может публиковать сам, если включить автоответ.

Площадки в одном интерфейсе. Сводка по ним — на странице «Аналитика».

## Как это работает

```
Wildberries, Ozon, Яндекс Маркет
   │  каждые 30 минут: неотвеченные отзывы; у Wildberries и Ozon ещё и вопросы
   ▼
worker.py ── разбор: нейросеть или правила + шаблоны ──► SQLite (data/reviewmate.db)
   │                                                          │
   │  маршрутизация:                                          ▼
   │   • вопрос покупателя ...................... менеджеру   web.py
   │   • отзыв, в котором есть вопрос ........... менеджеру    • очередь «Ждут ответа»
   │   • брак, не тот товар, безопасность ....... менеджеру    • карточка: черновик → «Опубликовать»
   │   • спам или оскорбления ................... менеджеру    • аналитика по площадкам
   │   • 5★ благодарность (если автоответ вкл.) . автоответ    • идеи для контента, журнал
   ▼
автоответ уходит через N минут (по умолчанию 60) — менеджер успевает отменить
```

Новая запись попадает в базу на ближайшей проверке, то есть не позже чем через 30 минут. Интервал меняется в «Настройках», есть кнопка «Проверить сейчас». Если на отзыв ответили прямо в кабинете Wildberries, сервис увидит это при следующей проверке и уберёт запись из очереди.

В очереди отзывы без текста не показываются: оценка без слов в разбор не идёт. Фильтр площадки и фильтр «Всё / Только вопросы / Только отзывы» стоят на разных строках.

## Площадки

| Площадка | Что нужно в `.env` | Что забираем |
|---|---|---|
| Wildberries | `WB_API_TOKEN`. Пока `DEMO_MODE=1`, кабинет не вызывается | неотвеченные отзывы и вопросы |
| Ozon | `OZON_CLIENT_ID` и `OZON_API_KEY`. Пусто или `DEMO_MODE=1` — кабинет не опрашивается | неотвеченные отзывы и вопросы |
| Яндекс Маркет | `YM_API_KEY` и `YM_BUSINESS_ID`. Пусто или `DEMO_MODE=1` — кабинет не опрашивается | отзывы, на которые продавец ещё не ответил |

Ключи Ozon: кабинет продавца → Настройки → API-ключи. Нужен доступ и к отзывам, и к вопросам. Ответ на отзыв уходит комментарием и помечает отзыв обработанным. Ответ на вопрос — отдельным методом, текст 2–3000 знаков, вместе с SKU товара.

Ключ Яндекс Маркета — с доступом «Общение с покупателями». `YM_BUSINESS_ID` — номер кабинета, его видно в `GET /v2/campaigns`.

Пока ключей Ozon или Маркета нет, сервис не выдумывает отзывы этих площадок. Тестовый набор `paperform_test_sets_ozon_ym.xlsx` загружается только при `DEMO_MODE=1` (файл ищется в `reviewmate-wb/data/`, в каталоге сервиса или на уровень выше). Это синтетические отзывы, не выгрузка кабинета. На площадку ничего не уходит, повторный запуск не затирает уже загруженные id. В рабочем режиме файл рядом с проектом в очередь не попадает, а уже загруженные тестовые строки скрыты.

`DEMO_MODE=1` отключает все три кабинета. Ключи Ozon и Маркета в этом режиме не вызываются: проверка их не опрашивает, кнопка «Опубликовать» не отправляет ответ покупателю и показывает, что это демо. Чтобы работать с настоящими кабинетами, поставьте `DEMO_MODE=0` и перезапустите сервис.

## Какой доступ к Wildberries нужен

**Один API-токен из кабинета продавца** (seller.wildberries.ru → профиль → Настройки → Доступ к API → «Создать токен»). Создаёт владелец кабинета или сотрудник, у которого есть доступ к этому разделу.

| Параметр токена | Что выбрать | Зачем |
|---|---|---|
| Категория **«Вопросы и отзывы»** | обязательно | Получать отзывы и вопросы, публиковать ответы, отклонять вопросы |
| Уровень доступа | **чтение и запись** (не «Только на чтение») | С токеном «только чтение» сервис покажет отзывы, но не отправит ответ |
| Категория **«Контент»** | желательно, достаточно чтения | Названия и описания товаров: нейросеть отвечает по фактам карточки |
| Остальные категории | не нужны | Токен не даёт доступа к деньгам, заказам и ценам |
| Тестовый режим (песочница) | нет | В песочнице нет реальных отзывов |

Что ещё важно:

- **Токен действует 180 дней.** После этого WB отвечает 401, и ответы перестают уходить. Сервис за 14 дней показывает предупреждение и, если подключён Telegram, присылает сообщение. Новый токен вставляется в `.env` → `WB_API_TOKEN`, затем сервис перезапускается.
- Токен показывается **один раз** при создании. Его передают администратору защищённым способом.
- Логин, пароль и СМС кабинета сервису не нужны.
- Если в кабинете несколько брендов, обрабатывается только Paperform (`BRAND_FILTER`).

Сохранённая выгрузка WB (если она загружена в базу) не смешивается с демо-отзывами: при `DEMO_MODE=1` опрос кабинета для этих записей не выполняется.

## Аналитика

Страница «Аналитика» сначала показывает три площадки по отдельности, затем общую сводку за 7, 30, 90, 365 дней или за всё время.

Блок «Что написали покупатели» — кнопки слева направо:

- **Критичные** — на них отвечают в первую очередь. Сначала те, что ещё ждут менеджера.
- **Не 5★**, **Негатив**, **Вопросы**, **Пожелания**, **Замечание в 5★** — группы по смыслу текста, а не только по числу звёзд. Негатив, вопрос и пожелание размечает нейросеть.
- **Идеи для контента** — последняя кнопка. Нейросеть схлопывает вопросы, пожелания и замечания в 5★ в темы для постов и сторис: новый цвет, состав комплекта, как пользоваться товаром с детьми. Это поводы, не готовые тексты. Пока набор отзывов тот же, темы берутся из кэша; когда состав меняется, сбор запускается в фоне.

## Режим автоответа

По умолчанию **выключен**: черновики ждут менеджера. Включается в «Настройках».

- автоматически отвечаем только на отзывы с оценкой не ниже порога (по умолчанию 5★) и сценарием из списка (по умолчанию «Благодарность»);
- **никогда автоматически**: вопросы, отзывы с вопросом внутри, приоритет «Высокий» или «Критичный», подозрение на спам;
- черновик проверяется перед отправкой: 2–5000 знаков, без ссылок, телефонов, мессенджеров, обещаний скидок и компенсаций, без незаполненных полей `{...}`;
- задержка перед публикацией (по умолчанию 60 минут) и дневной лимит (по умолчанию 100);
- если автоответ выключили, пока ответ ждал отправки, он возвращается менеджеру.

Тестовый набор Ozon и Маркета автоответ на площадку не отправляет.

## Вопросы покупателей

Вопросы Wildberries и Ozon, а также отзывы с вопросом внутри, всегда идут менеджеру. В очереди они стоят первыми. Черновик готовит нейросеть по описанию товара; без неё подставляется шаблон с полем `{впишите ответ на вопрос}`. Вопрос WB можно отклонить кнопкой «Отклонить вопрос» — отказ уходит в кабинет. Для вопроса Ozon та же кнопка только снимает его с очереди у нас, в кабинет Ozon отказ не отправляется. Ответ на вопрос WB модерирует сам маркетплейс.

## Запуск

Два процесса: `python worker.py` (проверка площадок и автоответы) и `python web.py` (интерфейс на http://127.0.0.1:8000). На Windows их запускают в двух окнах терминала из каталога `reviewmate-wb`.

```bash
pip install -r requirements.txt
python worker.py
python web.py
```

Вход в интерфейс — HTTP Basic, логин и пароль из `ADMIN_USER` и `ADMIN_PASSWORD`. Пароль читается при старте `web.py`: после правки `.env` процесс нужно перезапустить.

### Рабочий режим на сервере (Docker)

1. Получите токен WB и, если нужны другие площадки, ключи Ozon и Яндекс Маркета.
2. `cp .env.example .env` и заполните: `DEMO_MODE=0`, `WB_API_TOKEN`, `ADMIN_PASSWORD`, `SECRET_KEY`, по желанию ключи площадок, нейросеть и Telegram.
3. `docker compose up -d --build`
4. Откройте `http://<сервер>:8000`. Для доступа из интернета поставьте перед сервисом HTTPS (nginx или Caddy).
5. Первую неделю держите автоответ выключенным: проверяйте черновики и правьте `kb/templates.csv`.

Серверу нужен исходящий доступ к `feedbacks-api.wildberries.ru`, `content-api.wildberries.ru`, при включённых площадках — к `api-seller.ozon.ru` и `api.partner.market.yandex.ru`, и к API нейросети.

### Нейросеть

Подходит любой OpenAI-совместимый API (`LLM_BASE_URL`, `LLM_API_KEY` или `OPENAI_API_KEY`, `LLM_MODEL`). Без нейросети сервис классифицирует по ключевым словам и подставляет шаблоны. Если модель не ответила, черновик собирается по правилам. Модель, которая принимает только температуру по умолчанию, вызывается без параметра `temperature`.

## Настройка ответов

Все три файла базы знаний открываются в Excel или Google Таблицах и сохраняются как CSV UTF-8. После правки перезапустите `web.py` и `worker.py`.

- `kb/templates.csv` — шаблоны ответов по сценариям и темам. Нейросеть берёт их как образец тона, без нейросети они подставляются напрямую.
- `kb/faq.csv` — справочник фактов о товарах: колонки «товар» (часть названия: «Пиньята», «Гирлянда», «Конфетти», «Мини» или «Все»), «вопрос», «ключевые_слова» (через «;»), «ответ». Нейросеть отвечает на вопросы покупателей только по этим фактам и описанию карточки. Неизвестный факт записан как `{уточнить: …}` — такой ответ не уйдёт, пока менеджер не впишет факт. Чем больше полей заполнено, тем меньше ручной работы.
- `kb/keywords.csv` — словарь формулировок для разбора без нейросети и для страховки: даже если нейросеть ошибётся, вопрос или критичный случай, найденный по словарю, не потеряется. Колонки:
  - «группа»: `Тема: <название>` (порядок строк — приоритет тем, побеждает первая найденная), `Негатив`, `Позитив`, `Не успели к празднику`, `Угроза жалобы`, `Спам`, `Вопрос`, `Пожелание`;
  - «слово»: основа или фраза строчными буквами;
  - «поиск»: `основа` — слово начинается с этих букв («порани» находит «поранил», «поранилась»); `целиком` — только отдельным словом («в глаз», но не «в глаза»); `подстрока` — где угодно в тексте.
  Ошибка в группе или режиме поиска останавливает запуск с номером строки — так опечатка не пройдёт незаметно. После правки запустите `python -m pytest`.
- Подпись, стоп-слова, пороги автоответа и интервал проверки меняются в «Настройках».
- Системный промпт — `SYSTEM` в `app/analyzer.py`, правила маршрутизации — `app/guard.py`.

## Вольные запросы и отчёт

- **Спросить** — отдельная страница: менеджер задаёт вопрос обычными словами («Какие проблемы повторяются у пиньяты „Бомба“?», «Сравни площадки») и выбирает период, площадку и товар. Программа считает сводку по базе и отбирает до 60 самых значимых отзывов, нейросеть отвечает по этим данным. Имена покупателей в запрос не передаются.
- **Карточка отзыва** — кнопки «Короче», «Официальнее», «Теплее» переписывают черновик; «3 варианта» показывает короткий, стандартный и развёрнутый ответ, любой подставляется в черновик одной кнопкой. Факты и поля `{уточнить: …}` при переписывании сохраняются.
- **Аналитика → Отчёт за период** — «Выводы нейросети» пишут главное за период и три рекомендации с ответственными (кэш до изменения цифр), «Скачать отчёт (Excel)» выгружает сводку, товары, темы, повторяющиеся проблемы, критичные отзывы и выводы, «Скопировать отчёт» кладёт текст отчёта в буфер обмена для письма или мессенджера. Цифры считает программа, нейросеть их не пересчитывает.

Без нейросети эти кнопки показывают понятное сообщение; выгрузка отчёта работает и без неё.

## Ограничения API, которые учтены

Wildberries:

- около одного запроса в секунду к методам «Вопросы и отзывы»; при 429 клиент ждёт столько, сколько указано в `X-Ratelimit-Retry`;
- ответ на отзыв: 2–5000 знаков; сервис сам ответ не редактирует;
- неотвеченные отзывы уходят в архив WB через 30 дней;
- ошибки 401 и 403 не повторяются: в интерфейсе появляется предупреждение о токене.

Ozon и Яндекс Маркет: при 429 и сетевой ошибке запрос повторяется, 401 и 403 считаются ошибкой ключа и пишутся в журнал. Идентификаторы этих площадок в базе хранятся с префиксом `ozon:` и `ym:`, чтобы не пересечься с id Wildberries.

## Структура

```
app/config.py         настройки из .env, список площадок
app/wb_client.py      API Wildberries: отзывы, вопросы, карточки
app/ozon_client.py    API Ozon: отзывы, вопросы и ответы на них
app/ym_client.py      API Яндекс Маркета: отзывы и ответ
app/mock_wb.py        демо-данные вместо WB
app/sample_set.py     тестовый xlsx Ozon и Маркета
app/analyzer.py       разбор: нейросеть или правила + шаблоны
app/content_ideas.py  темы для соцсетей из вопросов, пожеланий и замечаний
app/report.py         отчёт за период: цифры, текст, Excel
app/assistant.py      переписать черновик, 3 варианта, вопрос к данным, выводы по отчёту
app/guard.py          проверки ответа и правила «автоответ / менеджер»
app/pipeline.py       опрос, маршрутизация, отправка
app/notify.py         Telegram
worker.py             фоновый опрос и автоответы
web.py, templates/    интерфейс менеджера
kb/templates.csv      база шаблонов ответов
kb/faq.csv            справочник фактов о товарах
kb/keywords.csv       словарь формулировок для разбора без нейросети
tests/                автотесты (pytest)
```
